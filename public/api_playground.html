Create Template from HTML
POST /api/templates/html
Tag syntax: {{Field Name}} {{Field Name|type}} {{Field Name|select|Opt1,Opt2}}
Types: text, signature, initials, date, image, checkbox, select, number, phone, file 

                

            

        


        
        

            

                
Create Template from Tagged PDF

                

                    POST
                    /api/templates/pdf
                

                

                    Upload a PDF that contains {{tags}} in its text layer.
                    Tags are detected, positioned, and removed from the final document.

Create Template from Tagged DOCX / DOC

                

                    POST
                    /api/templates/docx
                

                

                    Upload a DOCX or DOC file. DOCX files can contain
                    {{tags}} for auto field detection.
                    DOC files will be converted to PDF but tags cannot be auto-extracted (add fields manually).
                    Requires Gotenberg running for conversion.
